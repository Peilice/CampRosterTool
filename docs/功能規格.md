# 功能規格：報名資料轉換（網頁版）

> 本文件描述程式**應有**的行為。程式與本文件不一致時，以本文件為準，修改程式配合。
> 本文件所有範例資料皆為虛構。

## 1. 背景

元亨寺每年舉辦暑期學佛營，分兩個梯次，學員依性別分開管理。報名有兩種管道：

- **網路報名**：家長在報名系統填表，系統匯出 `.xls`。名額滿了以後的報名列為**候補**。
- **現場報名**：工作人員現場登記，並**當場發給學員一個號碼**。之後補登到同一份原始檔，或另外以 Google 表單匯出。

行政組需要把原始報名資料整理成四種報表，用於公告錄取名單、製作學員卡片、報到、編隊。本工具在瀏覽器中完成整理、分類、編號，並產生這四種報表。

名單**公告之後，已經發出去的編號不能再變動**。候補轉正取、正取取消報名時，都必須以不影響其他人編號的方式處理（§5）。

## 2. 名詞

| 名詞 | 說明 |
|---|---|
| 原始檔 | 使用者上傳的報名資料 Excel 檔 |
| 列號 | 資料在原始檔工作表中的列號，和用 Excel 開啟時左側看到的數字相同 |
| 梯次 | 第一梯、第二梯 |
| 組別 | 梯次 × 性別，共四組：第一梯男、第一梯女、第二梯男、第二梯女 |
| 來源 | 網路報名或現場報名 |
| 項次 | 原始檔中的號碼。網路報名代表報名順序；現場報名代表**現場發給學員的號碼** |
| 編號 | 本工具為每位學員產生的 6 碼學員編號，見 §5 |
| 補登資料 | 已經按編號規則完成編號的現場報名資料（通常來自 Google 表單），見 §3.4 |
| 狀態 | 正取、候補、轉正、取消，見 §4.2 |

## 3. 輸入

### 3.1 檔案格式

接受兩種格式：

- `.xlsx`
- 網路報名系統匯出的 `.xls`。這種檔案實際上是 XML 格式（SpreadsheetML），不是傳統二進位 `.xls`。

判斷方式：副檔名為 `.xlsx` 就當 xlsx 讀；其他情況看檔案開頭 200 bytes 是否含 `<?xml`，有就當 SpreadsheetML 讀，否則當 xlsx 讀。

### 3.2 尋找資料表與表頭

- 依序檢查每個工作表，採用**第一個找到表頭列的工作表**。
- **表頭列**：該列的欄位名稱經過正規化（§3.3）後，同時包含 `學員姓名`、`身分證字號`、`參加梯次`、`性別` 四個欄位。
- 同一個工作表可以有**多個表頭列**，每個表頭列到下一個表頭列（或表尾）之間是一個**資料區塊**。各區塊轉成標準欄位後合併，並記錄每筆資料的列號。
- 全部欄位都是空白的列略過。
- 所有工作表都找不到表頭列時，不准產生（§7.3）。

### 3.3 欄位名稱正規化

1. 去除前後空白。
2. 去除開頭的數字編號，例如 `3. 性別`、`3．性別` → `性別`。
3. 套用別名對照：

| 原始欄位名稱 | 標準欄位 |
|---|---|
| 生日：(民國年)/月/日（例：104/05/06） | 出生年 |
| 身份證字號 | 身分證字號 |
| 通訊地址 | 地址 |
| 學員目前就讀學校(縣市/校名) | 學員目前就讀學校 |
| 報名梯次 | 參加梯次 |
| 緊急聯絡人姓名 | 緊急連絡人姓名 |
| 健康狀況（風險評估） | 學童健康狀況（風險評估）() |
| 活動中有身體不適或意外，當下聯繫不上家長時： | 活動中，如有身體不適或意外，當下聯繫不上家長時： |

**標準欄位**（共 27 欄，依序）：來源、項次、學員姓名、性別、出生年、月、日、身分證字號、縣市、郵遞區號、地址、家長姓名、家長行動電話、EMAIL、學員目前就讀學校、學員就讀年級、參加梯次、(第一梯次)是否有意願上台進行才藝表演、以前是否參加過元亨寺暑期學佛夏令營、緊急連絡人姓名、緊急連絡人電話、緊急連絡人與學員關係、學童健康狀況（風險評估）()、學員特殊狀況說明、活動中，如有身體不適或意外，當下聯繫不上家長時：、管理者註記事項、現場原始編號。

原始檔沒有的欄位一律留空。

### 3.4 兩種資料區塊

| | 原生區塊 | 補登區塊 |
|---|---|---|
| 判斷 | 表頭含 `項次` | 表頭不含 `項次` |
| 來源 | 取 `來源` 欄；空白時視為**網路報名** | 一律視為**現場報名** |
| 項次 | 取 `項次` 欄 | `編號` 欄去掉第 1 碼 |
| 現場原始編號 | 空白 | `編號` 欄原值 |

### 3.5 欄位值的解讀

- **梯次**：`參加梯次` 含「第一梯次」→ 第一梯；含「第二梯次」→ 第二梯；都沒有 → 無法辨識。網路報名系統的實際值會附加年級或日期，例如「第一梯次：暑假後升國小五年級-國中二年級」，只要包含關鍵字即可。
- **候補**：`參加梯次` 含「候補」→ 候補，例如「第一梯次：暑假後升國小五年級-國中二年級(候補)」。
- **性別**：去除空白後必須是 `男` 或 `女`，否則無法辨識。
- **來源**：含「現場」→ 現場報名；含「網路」→ 網路報名；都沒有 → 無法辨識。
- **空白值**：`學員特殊狀況說明`、`管理者註記事項` 去除前後空白（含不換行空白）後，若是空字串、`無` 或 `--`，一律視為空白，報表中不顯示。
- **出生年月日**：分成 `出生年`、`月`、`日` 三欄，出生年為民國年。若 `月`、`日` 都空白，就嘗試從 `出生年` 解讀整串日期：
  1. 全形 `／`、`－`、`．` 先轉成半形。
  2. 以 `/`、`-`、`.` 分成三段 → 年、月、日。
  3. 沒有分隔符號的 7 碼數字 → 前 3 碼為年、中 2 碼為月、後 2 碼為日。
  4. 年份大於 1911 時視為西元年，減 1911 轉成民國年。這條規則也套用在原本就分開填寫的 `出生年`。
  5. 仍然無法解讀時保留原值，並顯示警告（§7.2）。

| 範例 | 出生年 | 月 | 日 | 解讀結果 |
|---|---|---|---|---|
| 一般 | 104 | 5 | 6 | 104/05/06 |
| 整串填在出生年 | 104/05/06 | | | 104/05/06 |
| 橫線分隔 | 104-5-6 | | | 104/05/06 |
| 全形斜線 | 104／05／06 | | | 104/05/06 |
| 無分隔 7 碼 | 1040506 | | | 104/05/06 |
| 西元年 | 2015/05/06 | | | 104/05/06 |
| 西元年、分開填 | 2015 | 5 | 6 | 104/05/06 |
| 無法解讀 | 104年5月 | | | 保留原值，顯示警告 |

## 4. 學員的辨識與狀態

### 4.1 排除

每筆資料列依序檢查：

1. 梯次、性別、來源任一項無法辨識 → **排除**：不編號、不進報表，只出現在「學員整理」的「原檔」分頁，整列標為**橘色**，並逐筆列出（§7.2）。
2. 有 `現場原始編號`，但其第 1 碼與該筆實際的梯次、性別不符（§5.1） → **編號衝突**，排除：在「原檔」分頁整列標為**黃色**，並逐筆列出（§7.2）。
3. 其餘資料依 §4.2 判斷狀態。

| 範例 | 參加梯次 | 性別 | 來源 | 現場原始編號 | 結果 |
|---|---|---|---|---|---|
| 正常 | 第一梯次(國曆7月7日~11日) | 男 | 網路報名 | | 有效 |
| 梯次空白 | | 女 | 現場報名 | | 排除，標橘色 |
| 性別打錯 | 第二梯次 | 南 | 網路報名 | | 排除，標橘色 |
| 編號衝突 | 第二梯次 | 女 | 現場報名 | 200012 | 排除，標黃色（第二梯女應為 3 開頭） |
| 補登相符 | 第二梯次 | 女 | 現場報名 | 300012 | 有效 |

### 4.2 狀態

狀態由 `參加梯次` 是否含「候補」，以及 `管理者註記事項` 的**標記**決定。

**標記**：`管理者註記事項` 去除前後空白後，以下列文字**開頭**才算標記，後面可以再接其他備註：

| 標記 | 寫法 | 例子 |
|---|---|---|
| 取消 | `取消` | `取消`、`取消 家長來電` |
| 轉正 | `轉正` + 正整數 N | `轉正1`、`轉正12 已補繳費` |
| 轉正後又取消 | `取消` + `轉正N` | `取消 轉正1` |

轉正的候補後來取消時，要寫成「取消 轉正N」，保留原本的轉正 N。如果只寫「取消」，他的轉正名額就不見了，後面轉正的人號碼會往前挪。

只看開頭，所以「午餐取消」不會被當成取消，但「取消午餐」**會**。一般備註請不要用「取消」或「轉正」開頭。

| 狀態 | 條件 | 編號 | 名單分頁 | 其他報表 |
|---|---|---|---|---|
| 正取 | 不是候補，沒有取消標記 | 有 | 列出 | 列出 |
| 候補 | 是候補，沒有轉正、取消標記 | **無** | 列出，標示「候補」 | 不列出 |
| 轉正 | 是候補，有轉正標記 | 有，接在正取後面（§5.2） | 列出，標示「轉正」 | 列出 |
| 取消 | 有取消標記 | **保留**原本的號碼 | 列出，標示「取消」 | 不列出 |

- 「名單分頁」指「學員整理」的名單分頁（§6.1）。「其他報表」包括學員整理的網格、公告分頁，以及學員狀況總覽、報到及查詢資料、編隊。
- 取消的學員仍然占用號碼，其他人的號碼不會因此改變，只會空出一號。
- 候補取消：沒有號碼，名單分頁標示「取消」。
- 轉正後又取消（「取消 轉正N」）：保留轉正時的號碼，名單分頁標示「取消」。

### 4.3 需要人工處理的情況

| 情況 | 處理 |
|---|---|
| 現場報名的項次空白或不是整數 | **不准產生**（§7.3），逐筆列出缺現場號碼的學員，請補填項次後重新上傳 |
| 同一組別內，兩筆以上現場報名的項次相同 | **不准產生**，逐筆列出 |
| 同一組別內，兩筆以上的轉正 N 相同 | **不准產生**，逐筆列出 |
| 有轉正標記，但不是候補 | 警告，視為正取 |
| 同一身分證字號出現兩次以上（不分大小寫，忽略空白） | 警告並逐筆列出，不自動刪除 |
| 出生年月日無法解讀 | 警告並逐筆列出 |

## 5. 編號規則

### 5.1 格式

編號共 6 碼數字：**第 1 碼是組別碼，後 5 碼是流水號**（前面補 0）。

| 組別 | 組別碼 |
|---|---|
| 第一梯男 | 0 |
| 第一梯女 | 1 |
| 第二梯男 | 2 |
| 第二梯女 | 3 |

### 5.2 流水號

同一組別內，現場報名與網路報名**分開編號**：

- **現場報名**：流水號 = 項次，也就是現場發給學員的號碼。若有 `現場原始編號`，直接沿用為編號。
- **網路報名**：
  1. 正取與取消（非候補）依項次由小到大排序，從 **51** 起流水編號。
  2. 有轉正 N 的候補（含轉正後又取消）接在後面，依 N 由小到大排序，繼續流水編號。
  3. 其餘候補（含候補取消）不編號。
- 某組別的現場號碼超過 50 時，會和網路報名的編號重疊。顯示警告，請人工確認。

範例（第一梯女）：

| 來源 | 項次 | 參加梯次 | 管理者註記事項 | 狀態 | 編號 |
|---|---|---|---|---|---|
| 現場報名 | 3 | 第一梯次 | | 正取 | 100003 |
| 現場報名 | 7 | 第一梯次 | 取消 | 取消 | 100007（保留） |
| 現場報名（補登） | 12 | 第一梯次 | | 正取 | 100012 |
| 網路報名 | 158 | 第一梯次 | | 正取 | 100051 |
| 網路報名 | 203 | 第一梯次 | 取消 家長來電 | 取消 | 100052（保留） |
| 網路報名 | 640 | 第一梯次 | | 正取 | 100053 |
| 網路報名 | 655 | 第一梯次(候補) | 轉正2 | 轉正 | 100055 |
| 網路報名 | 700 | 第一梯次(候補) | 轉正1 | 轉正 | 100054 |
| 網路報名 | 710 | 第一梯次(候補) | | 候補 | （無） |

### 5.3 排序

報表中的學員依下列順序排序：

1. 組別碼
2. 現場報名在前、網路報名在後
3. 有編號的依編號排序；沒有編號的（候補）排在最後，依項次排序

## 6. 輸出報表

使用者選擇報表類型、梯次（第一梯、第二梯、兩梯都要）、輸出檔名。下列「各組別」只包含使用者選擇的梯次。除了學員整理的名單分頁之外，所有報表都只列出**正取**與**轉正**的學員（§4.2）。

共通規則：

- 表頭列：深藍底（`#1F3864`）、白色粗體字。
- Excel 報表中某組別沒有學員時，仍產生該組別的分頁，內容只有表頭，讓檔案結構保持固定。
- 「出生年月日」格式為 `年/月/日`，月、日補成 2 位數，例如 `104/05/06`。
- `學員特殊狀況說明`、`管理者註記事項` 依 §3.5 處理空白值。

### 6.1 學員整理（.xlsx）

產生 **1 個檔案**：`{檔名}.xlsx`。

**「原檔」分頁**

- 列出原始檔的所有資料列，包括被排除的資料。
- 欄位為標準欄位去掉 `縣市`、`郵遞區號`。
- 無法辨識的資料列整列標**橘色**，編號衝突的資料列整列標**黃色**（§4.1）。

**每個組別各 3 個分頁**，依「第一梯男、第一梯女、第二梯男、第二梯女」的順序：

| 分頁 | 名稱範例 | 用途 | 列出誰 | 內容 |
|---|---|---|---|---|
| 名單 | `第一梯-男` | 內部名單 | 全部狀態 | 欄位：編號、項次、學員姓名、出生年月日、身分證字號、管理者註記事項、狀態。「狀態」欄只在候補、轉正、取消時填寫 |
| 網格 | `第一(男)` | 內部核對 | 正取、轉正 | 見下方網格版面，資料不遮蔽 |
| 公告 | `一公(男)` | 公開張貼錄取名單 | 正取、轉正 | 網格版面，姓名與身分證字號遮蔽 |

**網格版面**

- E1 是標題，例如「第一梯次(男)」。
- 每 50 人一個區塊，每個區塊佔 4 欄：編號、姓名、身分證字號、空白。區塊從左到右排列，每個區塊從第 2 列排到第 51 列。
- 資料儲存格加細黑框，並依組別上底色：

| 組別 | 底色 |
|---|---|
| 第一梯男 | 淺綠 `#CCFFCC` |
| 第一梯女 | 淺黃 `#FFFFCC` |
| 第二梯男 | 淺藍 `#CCECFF` |
| 第二梯女 | 淺紅 `#FFCCCC` |

**遮蔽規則**（公告分頁）

| 項目 | 規則 | 範例 |
|---|---|---|
| 姓名 1 字 | 不遮蔽 | 林 → 林 |
| 姓名 2 字 | 保留第 1 字，第 2 字改 ○ | 王明 → 王○ |
| 姓名 3 字以上 | 保留頭尾，中間每字改 ○ | 陳小美 → 陳○美；歐陽小明 → 歐○○明 |
| 身分證字號 6 碼以下 | 不遮蔽 | |
| 身分證字號 7 碼以上 | 保留前 3 碼、後 3 碼，中間改 `****` | A123456789 → A12****789 |

### 6.2 學員狀況總覽（.docx）

**每個組別產生 1 個檔案**：`{檔名}_第一梯_男.docx` 等。

- 某組別沒有學員時**不產生檔案**，改在下載區提示，例如「第二梯女沒有學員，未產生檔案」。
- A4 寬度，四邊邊界 0.5 吋。
- 每頁 4 張卡片，排成 2 × 2 表格，每位學員一張。
- 卡片內容：

| 行 | 內容 |
|---|---|
| 編號： | 編號（粗體） |
| 姓名： | 學員姓名（粗體） |
| 隊名： | 空白，供手寫 |
| 注意事項： | `學員特殊狀況說明`，**紅色** |
| （兩行空白） | |
| 備註： | 空白，供手寫 |

### 6.3 報到及查詢資料（.xlsx）

**每個梯次產生 1 個檔案**：`{檔名}_第一梯.xlsx` 等。

**每個性別各 2 個分頁**：

| 分頁 | 名稱範例 | 第 1 列標題 | 第 2 列表頭 |
|---|---|---|---|
| 查詢 | `第一梯男查詢` | 元亨寺115年暑期學佛營第一梯學員(男)資料 | 編號、姓名、出生、月、日、身分證字號、地址、就讀學校、就讀年級、緊急連絡人、緊急連絡人電話 |
| 報到單 | `11501男` | 元亨寺115年暑期學佛夏令營學員報到單(第一梯次男生) | 報到、編號、姓名、年次、月、日、身分證字號、住址 |

- 年度用**產生檔案當天**的民國年。報到單分頁名稱是「民國年 + 2 位數梯次 + 性別」。
- 報到單的「報到」欄留空，供現場打勾。

### 6.4 編隊（.xlsx）

**每個梯次產生 1 個檔案**：`{檔名}_第一梯.xlsx` 等。分頁依序為：

1. `男隊名`、`女隊名`：欄位為性別、序號、隊名。男生 36 隊、女生 32 隊，隊名固定（見 `output_d.py` 的 `TEAM_NAMES`）。
2. 每個性別各 2 個分頁：
   - **原始資料**，例如 `第一梯-男-原始資料`：欄位為編號、學員姓名、出生年月日、身分證字號、管理者註記事項、學員特殊狀況說明。
   - **編隊**，例如 `第一梯-男-編隊`：每隊 8 列，欄位如下：

| 欄 | 內容 |
|---|---|
| 隊名 | 公式：依隊號查隊名分頁 |
| 隊號 | 1、2、3… |
| 隊員編號 | 1–8 |
| 學員編號 | **使用者填入**。淺藍底（`#CFE2F3`），格式為文字 |
| 姓名 | 公式：依學員編號查原始資料分頁；查不到就留空 |
| 注意事項 | 公式：依學員編號查原始資料分頁，顯示「學員特殊狀況說明；管理者註記事項」。任一方空白就只顯示另一方；查不到或兩者都空白就留空 |

   - 每隊最後一列加粗底線，區隔各隊。
   - 同一個學員編號填入超過一次時，該儲存格自動變成**紅色**（`#FFC7CE`），由條件式格式處理。
   - H、I 欄放使用說明，內容固定。

範例（注意事項）：

| 學員特殊狀況說明 | 管理者註記事項 | 編隊表注意事項 |
|---|---|---|
| 對花生過敏 | 家長要求和哥哥同隊 | 對花生過敏；家長要求和哥哥同隊 |
| 對花生過敏 | -- | 對花生過敏 |
| 無 | 家長要求和哥哥同隊 | 家長要求和哥哥同隊 |
| 無 | -- | （空白） |

## 7. 網頁操作

### 7.1 流程

1. **選擇原始檔**：點選或拖曳檔案。讀取完成後顯示筆數與訊息（§7.2），並在可以產生時啟用步驟 2。
2. **選擇報表**：選擇類型、梯次、檔名。
   - 檔名預設為報表類型名稱。切換類型時，如果檔名還是上一個預設值或空白，就跟著換成新的預設值。
   - 使用者輸入的檔名若已帶副檔名，例如 `學員整理.xlsx`，自動去掉副檔名。
   - 檔名中的 `\ / : * ? " < > |` 自動替換成 `_`。替換後若是空白，就使用預設值。
3. **下載**：列出產生的檔案。產生 2 個以上檔案時，另外提供 `{檔名}.zip` 一次打包下載，並放在清單最上面。

重新選擇原始檔會重新讀取；重新產生會取代上一次的下載清單。

### 7.2 讀取後的訊息

讀取完成後顯示「已讀取『檔名』：共 N 筆原始資料，其中 M 筆納入報表」。如果不准產生（§7.3），只顯示「共 N 筆原始資料」。接著依需要顯示下列警告。每則警告都要逐筆列出受影響的資料，格式為「第 812 列 王小明：原因」：

| 警告 | 例子 |
|---|---|
| 無法辨識，未納入報表 | 第 812 列 王小明：參加梯次空白 |
| 編號衝突，未納入報表 | 第 830 列 李小華：現場原始編號 200012 與第二梯女不符 |
| 身分證字號重複 | 第 15 列 陳小美、第 402 列 陳小美：身分證字號相同 |
| 出生年月日無法解讀 | 第 77 列 林大同：出生年「104年5月」 |
| 有轉正標記但不是候補 | 第 90 列 張小英：視為正取 |
| 現場號碼超過 50 | 第一梯女的現場號碼最大到 53，超過 50，編號會和網路報名重疊，請人工確認 |

讀取完成的那句話後面，附上各狀態人數的摘要，例如「（另有候補 34 人、取消 2 人）」。

### 7.3 不准產生

遇到下列情況時，步驟 2 維持停用，並以錯誤訊息逐筆列出原因，請使用者修正原始檔後重新上傳：

- 找不到符合預期欄位的工作表
- 現場報名缺少現場號碼（項次空白或不是整數）
- 同一組別的現場號碼重複
- 同一組別的轉正 N 重複

例子：

> 有 3 位現場報名學員缺少現場號碼，無法產生報表。請在原始檔的「項次」欄填入現場發給學員的號碼，再重新上傳。
> 第 812 列 王小明
> 第 813 列 李小華
> 第 820 列 陳小美

### 7.4 錯誤訊息

讀取或產生時發生預期外的錯誤，只顯示白話說明和下一步，例如「無法讀取這個檔案，請確認是報名系統匯出的原始檔，或另存成 .xlsx 後再試一次」。技術細節收在可展開的「顯示技術細節」裡，平常不展開，方便使用者回報問題。

## 8. 非功能需求

1. **資料不離開瀏覽器**（最重要）：所有讀取與轉換都在使用者的瀏覽器中執行，不得把原始檔或任何轉換結果傳到伺服器，包括分析、記錄、錯誤回報等用途。
2. **個資檔案不進 repo**（最重要）：`.xls`、`.xlsx`、`.docx` 一律不得提交到 repo，由 `.gitignore` 排除。測試與文件只能使用虛構資料。
3. **瀏覽器**：支援電腦版最新的 Chrome、Edge。其他瀏覽器不保證能用，但不刻意阻擋。
4. **需要連網**：執行環境 Pyodide 從 CDN（jsdelivr）載入，不支援離線使用。第一次開啟約需 10–30 秒。
5. **訊息要讓人看得懂**：網頁上的提示、警告、錯誤訊息，都要用一般行政人員看得懂的繁體中文，並說明下一步該怎麼做，不得直接顯示程式的錯誤堆疊或技術用語（§7.4）。
