# 報名資料轉換

將學佛營的原始報名 Excel 整理、分類、編號，產生學員整理、學員狀況總覽、報到及查詢資料、編隊等報表，以及公告用的錄取名單圖片。

**網頁：<https://peilice.github.io/CampRosterTool/>**

## 使用方式

1. 開啟網頁，選擇原始報名檔（`.xlsx`，或網路報名系統匯出的 `.xls`）。
2. 選擇要產生的檔案類型、梯次，並輸入輸出檔名。
3. 按「產生檔案」後下載。產生多個檔案時，可一次下載 zip 壓縮檔。

第一次開啟網頁時需要下載執行環境，約 10–30 秒，且必須連網。

## 隱私

- 資料只在使用者的瀏覽器中處理，不會上傳到任何伺服器。
- 含學員個資的檔案（`.xls`、`.xlsx`、`.docx`、`.png`）**不得**放進這個 repo。
