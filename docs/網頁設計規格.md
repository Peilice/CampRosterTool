# 網頁設計規格：報名資料轉換

> 本文件分兩部分：〈現況〉記錄 `index.html` 目前的設計；〈修改規則〉規定之後修改時必須遵守的原則。
> 程式與〈現況〉不一致時，以本文件為準；要改設計時，先改本文件再改程式。

## 現況

### 1. 整體結構

單一頁面 `index.html`，由上到下：

1. 標題「報名資料轉換」（每個字一塊積木，見 §5），以及一行說明文字。說明文字必須包含「資料只在本機瀏覽器中處理，不會上傳到任何伺服器」。
2. 三張步驟卡片：
   - 步驟 1：選擇原始報名檔
   - 步驟 2：選擇要產生的檔案（類型、梯次、檔名）
   - 步驟 3：下載
3. 頁尾說明文字。

步驟卡片依序啟用：還不能操作的卡片呈現**停用狀態**。讀取原始檔成功後啟用步驟 2，產生檔案成功後啟用步驟 3。

### 2. 版面

| 項目 | 值 |
|---|---|
| 內容最大寬度 | 1040px，水平置中 |
| 頁面內距 | 上 32px、左右 16px、下 64px |
| 卡片間距 | 22px（留空間給卡片右下的硬陰影） |
| 頁面背景 | `--bg` 底色加上 `--dots` 圓點花紋（每 20px 一點） |
| 窄螢幕斷點 | 480px 以下時，梯次選項由 3 欄改成 1 欄 |

### 3. 色彩

整體風格為「積木王國」：粗墨線框、硬陰影、紅藍黃綠積木色。所有顏色都定義成 `:root` 上的 CSS 變數，深色模式依系統設定（`prefers-color-scheme: dark`）自動切換。

| 變數 | 用途 | 淺色 | 深色 |
|---|---|---|---|
| `--bg` | 頁面背景、文字輸入框背景 | `#fff6d8` | `#14151e` |
| `--dots` | 頁面背景的圓點 | `rgba(29,29,43,.1)` | `rgba(255,255,255,.07)` |
| `--surface` | 卡片背景、步驟積木底色 | `#ffffff` | `#1f212d` |
| `--text` | 主要文字 | `#1d1d2b` | `#f1f2f8` |
| `--muted` | 次要文字（說明、提示、頁尾） | `#50556a` | `#a9adc0` |
| `--ink` | 所有元件的粗框線 | `#1d1d2b` | `#e9ebf5` |
| `--hard` | 硬陰影 | `#1d1d2b` | `#4b5070` |
| `--red` / `--blue` / `--yellow` / `--green` | 積木色：標題字塊、步驟 1／2／3 的標題列、按鈕（黃）、下載標籤（綠）、拖放區圖示（藍） | `#ff6a5c` / `#5b9bff` / `#ffcb2e` / `#3cc47c` | `#ff7d72` / `#7fb0ff` / `#ffd75e` / `#5fd897` |
| `--on-block` | 積木色上的文字 | `#1d1d2b` | `#14151e` |
| `--accent` | 單選按鈕顏色、鍵盤焦點外框 | `#2456d6` | `#8fb4ff` |
| `--accent-soft` | 一般提示背景、下載列 hover 背景 | `#e2ebff` | `#263156` |
| `--pick` | 選項選取、拖放區 hover 的背景 | `#ffe58a` | `#4a3f12` |
| `--warn-bg` / `--warn-text` | 警告訊息 | `#fff0b8` / `#5a4200` | `#3b3313` / `#f6dc8f` |
| `--error-bg` / `--error-text` | 錯誤訊息 | `#ffe1dc` / `#8a1f1f` | `#3d1e1e` / `#f2b3b3` |
| `--ok` | 成功狀態文字 | `#17773f` | `#6fe3a1` |

網頁配色獨立於 Excel 報表，不需要和報表表頭顏色一致。

### 4. 字型

- 字型堆疊：`system-ui, -apple-system, "Segoe UI", "Microsoft JhengHei", "PingFang TC", "Noto Sans TC", sans-serif`，不載入外部字型。以粗字重營造積木感：標題 900；卡片標題、欄位標題、按鈕 800；選項名稱 700。
- 行高 1.6。
- 字級：標題 1.5rem；卡片標題 1.05rem；內文 1rem；訊息 0.92–0.95rem；選項說明 0.82rem；頁尾 0.85rem。

### 5. 元件

共通規則：可操作或需要區隔的元件都用 3px `--ink` 粗框；卡片、選項、按鈕、標題字塊帶有向右下的 `--hard` 硬陰影（不模糊）。

| 元件 | 樣式 | 狀態 |
|---|---|---|
| 標題 `h1` | 每個字放進一塊 1.9em 見方的積木，依序用紅、黃、藍、綠底，各自微微旋轉，帶 3px 硬陰影。`h1` 加 `aria-label` 提供完整標題 | — |
| 步驟卡片 `section` | `--surface` 底、3px `--ink` 框、圓角 16px、6px 硬陰影；左右下內距 20px | 停用：`.disabled`，透明度 0.5，不能點擊 |
| 卡片標題 `h2` | 整條標題列上色，由卡片的 `--band` 決定：步驟 1 紅、步驟 2 藍、步驟 3 黃；下方 3px `--ink` 分隔線 | — |
| 步驟編號 `.step` | 38×26px 小積木，`--surface` 底、3px 框，上方用 `::before`、`::after` 畫兩個凸點 | — |
| 檔案拖放區 `.drop` | 3px 虛線框、圓角 14px，整區可點，上方有藍色積木圖示 | hover 或拖曳經過：背景改成 `--pick` |
| 選項 `.option` | 單選按鈕包在 3px 框、圓角 12px、3px 硬陰影的卡片裡，整張卡片可點 | hover：浮起 1px；選取：背景 `--pick`，浮起 2px、陰影加大到 5px |
| 檔案類型選項 | 自動排列，每欄最小 200px | — |
| 梯次選項 | 固定 3 欄（窄螢幕 1 欄） | — |
| 文字輸入框 | `--bg` 底、3px 框、圓角 10px；右側以 `--muted` 顯示副檔名 | — |
| 按鈕 | `--yellow` 底、`--on-block` 字、粗體、3px 框、圓角 12px、4px 硬陰影 | 按下：往右下貼平、陰影消失；處理中：透明度 0.5、游標顯示等待，文字改成「產生中…」 |
| 狀態文字 `.status` | 一般文字色 | 成功：`.ok`，`--ok` 色、粗體 |
| 訊息 `.notice` | 3px 框、圓角 12px。第一行是說明，下方可接逐筆清單（最高約 12 行，超過時清單內捲動）與可展開的「顯示技術細節」 | 警告 `.warn`、錯誤 `.error`、一般提示 `.info`（`--accent-soft` 底） |
| 下載清單 | 每個檔案一列，3px 框、圓角 12px；左邊檔名、右邊「下載」是綠色小標籤 | hover：背景 `--accent-soft`，向右移 3px；zip 那一列用粗體 |
| 鍵盤焦點 | 選項、輸入框、按鈕、下載列、拖放區取得焦點時顯示 3px `--accent` 外框 | — |
| 動態 | 浮起、按下、位移都是 0.1–0.15 秒的過場 | 系統設定「減少動態」時取消過場 |

### 6. 互動

- 開啟頁面時立即在背景載入執行環境，狀態文字顯示「程式初始化中（第一次開啟約需 10–30 秒）…」。載入完成後改成「程式已就緒，請選擇原始報名檔。」
- 產生檔案成功後，畫面平滑捲動到步驟 3。

## 修改規則

1. **顏色一律用變數**：不得在元件樣式中直接寫色碼。新增顏色時，必須在 `:root` 定義變數，並同時在深色模式區塊提供對應的值。
2. **沿用現有元件**：新的選項、訊息、按鈕，要先使用 §5 既有的樣式類別；確定不適用才新增，並補進本文件。
3. **狀態要用樣式類別表示**：停用、選取、成功、警告、錯誤等狀態，要用類別切換（例如 `.disabled`、`.ok`），不要在 JavaScript 裡直接改樣式。
4. **維持三步驟流程**：新功能要放進既有的步驟；如果真的需要新增步驟，先修改本文件。
5. **單一檔案、不用建置工具**：樣式與腳本直接寫在 `index.html`。只有 Pyodide 可以從外部 CDN 載入，不得新增其他外部資源，例如字型、CSS 框架、分析或追蹤腳本。這也是為了遵守功能規格 §8 的「資料不離開瀏覽器」。
6. **窄螢幕不出現水平捲軸**：新增的元件在 480px 以下也必須能正常顯示，不出現水平捲軸。
7. **訊息文字**：依功能規格 §8 第 5 點的要求撰寫。
