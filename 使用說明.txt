========================================
 報名資料轉換程式 - 使用說明
========================================

【用途】
將元亨寺暑期學佛營的網路/現場報名 Excel 原始資料，自動整理、分類、
編號，產生三種固定格式的報表檔案，供行政作業使用。


【檔案說明】
本資料夾內：
  報名資料轉換.exe   ← 執行本體，雙擊即可使用
  1.原檔.xls         ← 範例原始報名檔（格式參考用）
  2.學員整理.xlsx     ← 「學員整理」輸出範例
  3.學員狀況總覽.docx ← 「學員狀況總覽」輸出範例
  4.報到及查詢資料.xlsx ← 「報到及查詢資料」輸出範例
  main.py 等 .py 檔  ← 程式原始碼（一般使用不需理會）
  build.bat          ← 開發者用，重新打包 exe 的腳本
  requirements.txt   ← 開發者用，打包所需套件清單


【使用前準備】
1. 將「報名資料轉換.exe」與「原始報名 Excel 檔」放在同一個資料夾。
2. 不需要安裝 Python 或任何其他軟體，直接雙擊 exe 即可執行。


【使用步驟】
雙擊「報名資料轉換.exe」開啟後，先輸入原始檔名，再依序回答問題產生檔案：

1. 請輸入原始 Excel 檔名
   → 不需輸入副檔名，例如原始檔為「1.原檔.xls」，只需輸入：1.原檔
     程式會自動尋找 .xlsx 或 .xls 檔案，檔案必須跟 exe 放在同一資料夾。

2. 請選擇要製作的檔案類型
   → 1：學員整理（.xlsx）
   → 2：學員狀況總覽（.docx）
   → 3：報到及查詢資料（.xlsx）
   → 4：編隊（.xlsx）
   → 5：公告（.png）

3. 請選擇要製作哪一梯
   → 1：第一梯
   → 2：第二梯
   → 3：兩梯都要

4. 請輸入輸出檔名
   → 不需輸入副檔名，程式會自動加上（.xlsx 或 .docx）

完成後畫面會顯示「完成！檔案已儲存至：...」，
產生的檔案會存放在跟 exe 相同的資料夾中。

接著會詢問「是否再次生成檔案？(Y/N)」：
→ 輸入 Y：回到步驟 2，重新選擇檔案類型/梯次/輸出檔名，
  沿用同一份原始資料繼續產生下一個檔案（不需重新輸入原始檔名）。
→ 輸入 N（或直接按 Enter）：結束程式。


【三種輸出類型內容】

A. 學員整理.xlsx
   - 原檔：複製全部原始資料（移除縣市、郵遞區號欄，因地址已包含）
   - 每個「梯次×性別」各產生 2 張表：
     ‧ 第X梯-男/女：精簡名單（編號/項次/姓名/出生年月日/身分證/管理者註記）
     ‧ 第X(男/女)：每 50 筆一組橫向並排的版面（可列印用）
   - 公開張貼用的遮蔽版面改由「E. 公告」產生圖片檔

B. 學員狀況總覽.docx
   - 依「梯次×性別」分組，每組另起一頁
   - 每位學員一張卡片：編號/姓名/隊名（空白待填）/
     注意事項（僅在原始資料「學員特殊狀況說明」有實質內容時顯示）/備註（空白待填）

C. 報到及查詢資料.xlsx
   - 每個「梯次×性別」各產生 2 張表：
     ‧ 第X梯X查詢：完整查詢名單（含地址、學校、緊急連絡人等）
     ‧ 11X0X男/女（報到簽到表）：報到勾選欄 + 基本資料，供現場報到使用
       （代碼中的年度數字為程式執行當下的民國年，自動計算，不需手動修改）

D. 編隊.xlsx
   - 男隊名／女隊名：固定的隊伍名稱清單（男 36 隊、女 32 隊），兩梯共用
   - 每個「梯次×性別」各產生 2 張表：
     ‧ 第X梯-男/女-原始資料：該梯次/性別的學員名單，供編隊表查詢姓名、注意事項用
     ‧ 第X梯-男/女-編隊：每隊固定 8 個名額，藍色底格為「學員編號」欄，
       填入學員編號後會自動帶出隊名、姓名、注意事項
       - 同一個學員編號若被重複填入超過一次，該儲存格會自動標示紅色以利核對
       - 每隔一隊會有淺灰網底、且隊伍最後一列有粗底線，方便辨識各隊分界


E. 公告.png
   - 每個「梯次×性別」各產生 1 張圖片（沒有學員的組別不產生）
   - 每 50 人一個區塊由左到右排列，姓名、身分證做遮蔽處理（公開張貼用）
   - 第一次產生公告時會下載中文字型（約 5.7 MB）

【編號規則】
編號共 6 碼：第 1 碼為類別代碼，後 5 碼為流水號。
  類別代碼：0=第一梯男　1=第一梯女　2=第二梯男　3=第二梯女
  流水號：「現場報名」從 00001 開始；「網路報名」從 00051 開始
  （同一類別中，現場與網路報名各自流水編號，互不影響）

例如：第二梯、男生、網路報名的第 3 位學員 → 編號 200053


【常見問題】
Q: 出現「找不到檔案」？
A: 確認原始 Excel 檔名是否輸入正確（含副檔名），
   且該檔案確實與 exe 放在同一資料夾。

Q: 原始檔案格式跟預期不符，欄位讀不到？
A: 原始檔案的欄位名稱（如：學員姓名、身分證字號、參加梯次、性別等）
   必須與範例檔一致，程式才能正確辨識。

Q: 現場報名人數超過 50 人怎麼辦？
A: 程式會在畫面上印出警告訊息，提醒現場與網路報名的編號會重疊，
   請人工確認並協調處理。


【網頁版（GitHub Pages）】
index.html 為網頁版介面，透過 Pyodide 在瀏覽器中直接執行同一套 Python 程式，
功能與 exe 相同；所有資料都只在使用者的瀏覽器中處理，不會上傳到伺服器。
第一次開啟需下載執行環境（約 10–30 秒），之後瀏覽器會快取。

部署方式：
1. 將本資料夾推上 GitHub（.gitignore 已排除 .xls/.xlsx/.docx 等含個資的檔案，
   以及 build、dist 資料夾，請勿手動加入）。
2. 在 GitHub 專案的 Settings → Pages，Source 選「Deploy from a branch」，
   分支選 main、資料夾選「/ (root)」，儲存。
3. 數分鐘後即可透過 https://<帳號>.github.io/<專案名稱>/ 使用。
修改任何 .py 檔後重新推送，網頁版就會同步更新，不需另外打包。

本機測試：在本資料夾執行 python -m http.server，
再以瀏覽器開啟 http://localhost:8000/ 即可（直接雙擊 index.html 無法運作）。


【給開發者：如何修改程式後重新打包】
1. 安裝 Python 3.x
2. 在本資料夾開啟命令提示字元，執行：build.bat
   （會自動安裝所需套件並打包成新的 exe）
3. 新的 exe 會產生於 dist 資料夾中。
