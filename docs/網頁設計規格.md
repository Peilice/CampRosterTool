# 網頁設計規格：報名資料轉換

> 本文件分兩部分：〈現況〉記錄 `index.html` 目前的設計；〈修改規則〉規定之後修改時必須遵守的原則。
> 程式與〈現況〉不一致時，以本文件為準；要改設計時，先改本文件再改程式。

## 現況

### 1. 整體結構

單一頁面 `index.html`，由上到下：

1. 標題「報名資料轉換」，以及一行說明文字。說明文字必須包含「資料只在本機瀏覽器中處理，不會上傳到任何伺服器」。
2. 三張步驟卡片：
   - 步驟 1：選擇原始報名檔
   - 步驟 2：選擇要產生的檔案（類型、梯次、檔名）
   - 步驟 3：下載
3. 頁尾說明文字。

步驟卡片依序啟用：還不能操作的卡片呈現**停用狀態**。讀取原始檔成功後啟用步驟 2，產生檔案成功後啟用步驟 3。

### 2. 版面

| 項目 | 值 |
|---|---|
| 內容最大寬度 | 1040px，水平置中 |
| 頁面內距 | 上 32px、左右 16px、下 64px |
| 卡片間距 | 16px |
| 窄螢幕斷點 | 480px 以下時，梯次選項由 3 欄改成 1 欄 |

### 3. 色彩

所有顏色都定義成 `:root` 上的 CSS 變數，深色模式依系統設定（`prefers-color-scheme: dark`）自動切換。

| 變數 | 用途 | 淺色 | 深色 |
|---|---|---|---|
| `--bg` | 頁面背景、文字輸入框背景 | `#f6f4ef` | `#181715` |
| `--surface` | 卡片背景 | `#ffffff` | `#222120` |
| `--text` | 主要文字 | `#22201c` | `#ece9e3` |
| `--muted` | 次要文字（說明、提示、頁尾） | `#6b665d` | `#a39e94` |
| `--border` | 邊框 | `#e2ddd3` | `#3a3834` |
| `--accent` | 主色：按鈕、步驟編號、選取與 hover 的邊框 | `#1f3864` | `#8fb0e8` |
| `--accent-text` | 主色上的文字 | `#ffffff` | `#10182a` |
| `--accent-soft` | 選取與 hover 的背景 | `#e8edf6` | `#263248` |
| `--warn-bg` / `--warn-text` | 警告訊息 | `#fff6d6` / `#6b5300` | `#3a3214` / `#f0d98a` |
| `--error-bg` / `--error-text` | 錯誤訊息 | `#fde8e8` / `#8a1f1f` | `#3d1e1e` / `#f2b3b3` |
| `--ok` | 成功狀態文字 | `#2d6a3e` | `#8fd19e` |

淺色模式的主色 `#1f3864` 與 Excel 報表的表頭底色相同，讓網頁和產出的報表視覺一致。

### 4. 字型

- 字型堆疊：`system-ui, -apple-system, "Segoe UI", "Microsoft JhengHei", "PingFang TC", "Noto Sans TC", sans-serif`，不載入外部字型。
- 行高 1.6。
- 字級：標題 1.6rem；卡片標題 1.05rem；內文 1rem；訊息 0.92–0.95rem；選項說明 0.82rem；頁尾 0.85rem。

### 5. 元件

| 元件 | 樣式 | 狀態 |
|---|---|---|
| 步驟卡片 `section` | `--surface` 底、1px `--border` 框、圓角 12px、內距 20px | 停用：`.disabled`，透明度 0.5，不能點擊 |
| 步驟編號 `.step` | 24px 圓形，`--accent` 底 | — |
| 檔案拖放區 `.drop` | 2px 虛線框、圓角 10px，整區可點 | hover 或拖曳經過：框線改成 `--accent`，背景改成 `--accent-soft` |
| 選項 `.option` | 單選按鈕包在 1px 框、圓角 8px 的卡片裡，整張卡片可點 | 選取：框線改成 `--accent`，背景改成 `--accent-soft` |
| 檔案類型選項 | 自動排列，每欄最小 200px | — |
| 梯次選項 | 固定 3 欄（窄螢幕 1 欄） | — |
| 文字輸入框 | `--bg` 底、1px 框、圓角 8px；右側以 `--muted` 顯示副檔名 | — |
| 按鈕 | `--accent` 底、粗體、圓角 8px | 處理中：透明度 0.5、游標顯示等待，文字改成「產生中…」 |
| 狀態文字 `.status` | 一般文字色 | 成功：`.ok`，`--ok` 色 |
| 訊息 `.notice` | 圓角 8px。第一行是說明，下方可接逐筆清單（最高約 12 行，超過時清單內捲動）與可展開的「顯示技術細節」 | 警告 `.warn`、錯誤 `.error`、一般提示 `.info`（`--accent-soft` 底） |
| 下載清單 | 每個檔案一列，左邊檔名、右邊以 `--accent` 色顯示「下載」 | hover：框線 `--accent`、背景 `--accent-soft`；zip 那一列用粗體 |

### 6. 互動

- 開啟頁面時立即在背景載入執行環境，狀態文字顯示「程式初始化中（第一次開啟約需 10–30 秒）…」。載入完成後改成「程式已就緒，請選擇原始報名檔。」
- 產生檔案成功後，畫面平滑捲動到步驟 3。

## 修改規則

1. **顏色一律用變數**：不得在元件樣式中直接寫色碼。新增顏色時，必須在 `:root` 定義變數，並同時在深色模式區塊提供對應的值。
2. **沿用現有元件**：新的選項、訊息、按鈕，要先使用 §5 既有的樣式類別；確定不適用才新增，並補進本文件。
3. **狀態要用樣式類別表示**：停用、選取、成功、警告、錯誤等狀態，要用類別切換（例如 `.disabled`、`.ok`），不要在 JavaScript 裡直接改樣式。
4. **維持三步驟流程**：新功能要放進既有的步驟；如果真的需要新增步驟，先修改本文件。
5. **單一檔案、不用建置工具**：樣式與腳本直接寫在 `index.html`。只有 Pyodide 可以從外部 CDN 載入，不得新增其他外部資源，例如字型、CSS 框架、分析或追蹤腳本。這也是為了遵守功能規格 §8 的「資料不離開瀏覽器」。
6. **窄螢幕不出現水平捲軸**：新增的元件在 480px 以下也必須能正常顯示，不出現水平捲軸。
7. **訊息文字**：依功能規格 §8 第 5 點的要求撰寫。
